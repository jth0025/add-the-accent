I have a phrase I return to more than any other: now let's be real. It's always been my way out — my saving clutch back to the truth whenever I start slipping into the bullshit. Not literal. Subliminal. A safety word, if I need one.

So let's be real about where we actually are. The empty room is not the same thing as a clean room. A clean room is what you see on someone else's page: the color palette, the aesthetic, the bold ideas sitting next to the boring ones, all of it arranged for you to admire. You may never see the person behind it. Just the vision — clean, clear, curated.

The empty room is different. It's a seasonal period of reboot, not a performance. Neo waking up to the Source. The morning comes. The sun sets. The night arrives and stays peaceful. That stretch has always been mine — the timespace where I do my best, most efficient work.

An inefficient man doesn't feel beautiful. If I had to describe one, I'd point outside, to my own bewildered neighbors — rugged, jagged, free. Picasso smudged into something colossal. Giants who roam like they own the light. Still beautiful, if you ask me, just built differently than I am.

I can find God everywhere. See Him everywhere. But the sensation of that — at least for me — feels less like comfort and more like weight. Others probably find it liberating. I mostly hear it as a call: an endless pull toward purpose and intention, one that sounds, faintly, like the warmest morning. My comforting friend.

That liberation doesn't arrive on its own. It lies dormant in whatever I haven't made yet, waiting on me to create it — to build this life, to fulfill this purpose. That's the only real distinction that matters.

So back to the room we go. We clean it. We start over. We become giant, and we become free.

We cannot stay an inadequate man.
